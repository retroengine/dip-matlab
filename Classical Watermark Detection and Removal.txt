Classical Visible Watermark Detection, Localisation, and Removal in Single Photos
Evidence Map Formulation
Overlaid semi-transparent white watermarking introduces four concomitant photometric signatures into an image: local luminance elevation, color desaturation, local variance attenuation, and a uniform directional color shift towards pure white1. Single-image classical white top-hat filtering fails on natural high-contrast structures such as foliage, timber grain, and snow because top-hat operators measure only local intensity maxima without verifying color or variance consistency4. The proposed fused evidence map    combines top-hat luminance residual   , Hue-Saturation-Value (HSV) saturation drop   , contrast dampening ratio   , and RGB shift vector alignment   1. Multiplying these four normalized cues selectively isolates translucent white glyphs while suppressing high-contrast natural background edges1.






Matlab
% Step 1: Input conversion and background structure estimation
J = im2double(I_input);
J_gray = rgb2gray(J);
se_bg = strel('disk', 15);
J_bg = imopen(J, se_bg);
J_bg_gray = rgb2gray(J_bg);

% Step 2: Photometric cue extraction
T = imtophat(J_gray, strel('disk', 5));
hsv = rgb2hsv(J);
S_drop = 1.0 - hsv(:,:,2);

% Step 3: Local variance attenuation ratio
nhood = true(7);
std_J = stdfilt(J_gray, nhood);
std_bg = stdfilt(J_bg_gray, nhood);
C_ratio = max(0, 1.0 - (std_J ./ (std_bg + 1e-3)));

% Step 4: RGB shift vector alignment towards white (1, 1, 1)
dC = J - J_bg;
dW = 1.0 - J_bg;
norm_dC = sqrt(sum(dC.^2, 3));
norm_dW = sqrt(sum(dW.^2, 3));
V_align = max(0, sum(dC .* dW, 3) ./ (norm_dC .* norm_dW + 1e-4));

% Step 5: Fused evidence map creation
E = imgaussfilt(T .* S_drop .* C_ratio .* V_align, 0.8);

Periodic (Tiled) Detection from One Image
Tiled watermarks present two-dimensional spatial repetitions across the image plane1. Direct 2D autocorrelation on raw image intensities fails because non-stationary low-frequency background textures generate dominant low-frequency correlation lobes3. Applying 2D spatial autocorrelation    to a high-pass zero-mean evidence map    isolates the repeating translation vectors8. The two shortest non-collinear displacement peaks are identified using 2D quadratic surface fitting to achieve sub-pixel accuracy, while periodic structure presence is validated using a Peak-to-Sidelobe Ratio (PSR) threshold8.






Matlab
% Step 1: Zero-mean high-pass filtering of evidence map
E_hp = E - imgaussfilt(E, 8.0);

% Step 2: 2D FFT-based spatial autocorrelation
F_E = fft2(E_hp);
R_EE = real(ifft2(F_E .* conj(F_E)));
R_EE = fftshift(R_EE) / numel(E_hp);

% Step 3: Peak detection and masking central autocorrelation lobe
[M, N] = size(R_EE);
cx = floor(N/2) + 1; cy = floor(M/2) + 1;
R_center = R_EE;
R_center(cy-10:cy+10, cx-10:cx+10) = 0;

% Step 4: Sub-pixel peak identification and PSR validation
regional_max = imregionalmax(R_center);
peak_indices = find(regional_max & (R_center > 0.15 * max(R_center(:))));

sidelobe_mean = mean(R_EE(:));
sidelobe_std = std(R_EE(:));
peak_val = max(R_center(peak_indices));
PSR = (peak_val - sidelobe_mean) / (sidelobe_std + 1e-6);

% Decision threshold for periodicity
is_tiled = PSR > 4.5;

Repeated-Logo Detection
When photos feature unlatticed repeating graphical logos (~7 instances), template mining combined with normalized cross-correlation (normxcorr2) provides robust detection without requiring deep learning or SIFT feature matching8. The template is mined automatically by selecting the bounding box of the highest-energy connected component within the evidence map   5. Correlation response maps are thresholded dynamically using Median Absolute Deviation (MAD) statistics to accommodate varying background clutter9. Repeated instances are confirmed when 4 to 12 distinct spatial correlation peaks exceed the adaptive threshold8.






Matlab
% Step 1: Automatic template mining from highest-energy region
CC_e = bwconncomp(E > 0.3 * max(E(:)));
stats_e = regionprops(CC_e, E, 'BoundingBox', 'Area');
[~, max_idx] = max([stats_e.Area]);
bb = round(stats_e(max_idx).BoundingBox);
T_template = J_gray(bb(2):bb(2)+bb(4)-1, bb(1):bb(1)+bb(3)-1);

% Step 2: Compute Normalized Cross-Correlation
C_map = normxcorr2(T_template, J_gray);
[tM, tN] = size(T_template);
C_map = C_map(tM:end-tM+1, tN:end-tN+1);

% Step 3: Robust peak thresholding using Median Absolute Deviation
med_c = median(C_map(:));
mad_c = median(abs(C_map(:) - med_c));
T_corr = max(0.50, med_c + 4.5 * (1.4826 * mad_c));

% Step 4: Instance validation
peaks = imregionalmax(C_map) & (C_map > T_corr);
CC_peaks = bwconncomp(peaks);
is_repeated_logo = (CC_peaks.NumObjects >= 4) && (CC_peaks.NumObjects <= 12);

Single Watermark Localisation Without Hand Hints
Single isolated text bands or corner logos are localized by evaluating morphological stroke width consistency alongside structural edge density constraints5. Stroke width is computed efficiently in classical MATLAB using the Euclidean distance transform applied directly along the morphological skeleton of Canny edge maps13. Candidate connected components are evaluated based on bounding box aspect ratio, solidity, and stroke width variance consistency5. Regions satisfying text-likeness metrics are dilated and merged to generate a clean binary watermark mask5.






Matlab
% Step 1: Edge detection and distance-skeleton stroke mapping
B_edges = edge(J_gray, 'Canny');
dist_trans = bwdist(~B_edges);
skel = bwmorph(B_edges, 'thin', Inf);
stroke_map = 2.0 * dist_trans .* skel;

% Step 2: Connected component text-likeness scoring
CC_text = bwconncomp(imdilate(B_edges, strel('disk', 2)));
stats_text = regionprops(CC_text, 'BoundingBox', 'Solidity');
valid_mask = false(size(J_gray));

for k = 1:CC_text.NumObjects
   idx = CC_text.PixelIdxList{k};
   sw_vals = stroke_map(idx);
   sw_vals = sw_vals(sw_vals > 0);
   
   if ~isempty(sw_vals)
       sw_cov = std(sw_vals) / (mean(sw_vals) + 1e-4);
       ar = stats_text(k).BoundingBox(3) / stats_text(k).BoundingBox(4);
       
       if (sw_cov < 0.45) && (stats_text(k).Solidity < 0.85) && (ar > 0.2 && ar < 12.0)
           valid_mask(idx) = true;
       end
   end
end
final_single_mask = imclose(valid_mask, strel('disk', 4));

Alpha Estimation and Removal
The opacity scaling factor    is estimated by minimizing the Total Variation (TV) of the recovered background image within a narrow morphological boundary band surrounding the watermark mask1. The physical matting model    (with pure white   ) is inverted analytically to yield   1. To eliminate JPEG blocking artifacts and edge ringing along character boundaries, guided filter residual refinement is applied to the difference between the inverted image and the original input photo1.






Matlab
% Step 1: Extract boundary band d_Omega
mask_d = imdilate(final_single_mask, strel('disk', 3));
mask_e = imerode(final_single_mask, strel('disk', 3));
d_Omega = mask_d & ~mask_e;

% Step 2: Optimize a0 via Total Variation minimization on d_Omega
tv_loss = @(a0) compute_tv(J, final_single_mask, d_Omega, a0);
best_a0 = fminbnd(tv_loss, 0.20, 0.50);

% Step 3: Analytical matting inversion
alpha_map = best_a0 * double(final_single_mask);
I_rec = min(max((J - alpha_map) ./ max(1e-4, 1.0 - alpha_map), 0.0), 1.0);

% Step 4: Guided filter residual refinement for JPEG artifact mitigation
residual = I_rec - J;
residual_refined = imguidedfilter(residual, J, 'NeighborhoodSize', 5, 'DegreeOfSmoothing', 1e-3);
I_final = J + residual_refined;

function tv = compute_tv(J, m, dO, a0)
   a_m = a0 * double(m);
   I_t = (J - a_m) ./ max(1e-4, 1.0 - a_m);
   [gx, gy] = imgradientxy(rgb2gray(I_t));
   tv = sum(abs(gx(dO)) + abs(gy(dO)));
end

Inpainting Settings
When watermark opacity approaches saturation (  ) or underlying background detail is destroyed, classical image inpainting restores target regions18. Thin text scripts require PDE-based coherence transport (inpaintCoherent) with small neighborhood radii and minimal smoothing factors to propagate linear contours seamlessly18. Large bold characters and graphical logos require exemplar patch-based synthesis (inpaintExemplar) using tensor fill priorities and patch sizes proportional to maximum stroke widths19. Segmenting the mask by component area allows applying structure transport to fine character strokes and exemplar synthesis to thick logos14.






Matlab
% Step 1: Partition mask into thin vs. bold components
CC_inp = bwconncomp(final_single_mask);
stats_inp = regionprops(CC_inp, 'Area');
mask_thin = false(size(final_single_mask));
mask_bold = false(size(final_single_mask));

for k = 1:CC_inp.NumObjects
   if stats_inp(k).Area < 150
       mask_thin(CC_inp.PixelIdxList{k}) = true;
   else
       mask_bold(CC_inp.PixelIdxList{k}) = true;
   end
end

% Step 2: Sequential execution using optimal settings
J_step1 = inpaintCoherent(J, imdilate(mask_thin, strel('disk', 1)), ...
   'SmoothingFactor', 0.5, 'Radius', 2);

J_final_inpainted = inpaintExemplar(J_step1, imdilate(mask_bold, strel('disk', 3)), ...
   'FillOrder', 'tensor', 'PatchSize', [9 9]);

Evaluation
Quantitative evaluation of watermark detection and removal protocols requires synthetic test datasets constructed using clean ground-truth images    and known alpha masks   1. Mask segmentation accuracy is evaluated against ground truth using Precision, Recall, and F1-Score6. Image reconstruction performance across restored regions is measured using Peak Signal-to-Noise Ratio (PSNR) and Structural Similarity (SSIM) metrics1. Test protocols should vary opacity    and JPEG compression quality factors (  ) to simulate realistic digital photo degradation6.

Precision = TP / (TP + FP + 1e-6);
Recall = TP / (TP + FN + 1e-6);
F1_score = 2 * (Precision * Recall) / (Precision + Recall + 1e-6);
